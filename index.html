02 / AGENTIC AI WORKFLOWCOMPLETED LOCAL PROTOTYPE

Codebase Issue Triage Agent

A local LLM workflow that assesses software issues and decides when to inspect a repository. It returns structured triage and evidence for human review.

DECISION

LangGraph routes each issue to read-only repository search or directly to a result.

OUTPUT

Pydantic validates category, priority, confidence, rationale, labels, and a draft response.

STACK

Python, LangChain, Ollama, LangGraph, Pydantic, and Pytest.

Inside the workflow +
  1. The Python CLI accepts a validated issue title and description.
  2. LangChain calls a local Ollama model. Pydantic validates its structured JSON result.
  3. LangGraph routes the issue according to the repository-investigation decision.
  4. When needed, read-only text search records matching file paths, lines, and excerpts.
  5. The final JSON includes triage, investigation status, evidence, labels, and a draft response for review.

The workflow suggests an assessment. A person reviews it before acting.
